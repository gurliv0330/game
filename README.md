# game
A game where 2 characters work with the same keys

Okay so following the theme 'split' the concept of the game is basically that there is going to be 2 worlds. In the left half of the screen, there is the daylight world and on the right half it's night. So basically there are 2 different characters on each side. 'Sol' on the sunlight side and 'Luna' on the night one. So they both move with the same keys. So if you press the left arrow key to move 'Sol' towards the left, 'Luna' will move towards the left too. So what You have to do is try to sync them both up and get them both to the end of each level.
